# Architecture Decision Records

This directory records decisions that should outlive a single PR or issue.

Use short files named `NNNN-title.md`. Status values:

- `Proposed`: still being debated or validated.
- `Accepted`: decision is active.
- `Superseded`: kept for history, replaced by a later ADR.

Each ADR should cover context, decision, consequences, and migration notes when
the decision changes existing behavior.
